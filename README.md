# Mirrorlog PWA

## Setup
1. Clone repo
2. Run `npm install`
3. Run `npm run dev` to start local dev server

## Sprint Roadmap
- Sprint 1: Core structure + tagging + streaks
- Sprint 2: Anchors + Highlights + Search
- Sprint 3: AI Integration + Cloud Sync

## Contribution Guidelines
- Commit small, focused changes.
- Use feature branches, merge into dev first.
